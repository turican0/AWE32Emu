AweVBank 96 FINAL BUILD 1000:

About the program:
------------------

AweVBank is the Explorer to your Awe32 Soundcard. So all the things you can 
do in the explorer also work in AweVBank. This means that you can 
copy/paste patches, drag&drop them, move them, right-click them etc.

All things you do are done automatically to the Awe32. So if you delete a patch
from the list or move it to another location, the changes are also done to the
Awe32. You do not need to make any 'Upload changes' or stuff like that.

Via it's plugin interface AweVBank is now able to work with external files as if
they where SoundFonts. There are some sample plugins for MOD, WAV, SM3 and 669
files. If you want to write your own plugins. Contact me.

You're also able to change parameters of the patches.

AweVBank comes with extensive online help. You can press F1 anywhere or use the
context help with Shift-F1.


Short Feature List:
-------------------

* Win95 explorer like interface
* SF2 compatible
* Full replacement of AWECP
* SF2 parameter editor
* Full Undo/Redo (50 steps)
* Reads MOD, WAV, SM3, 669, SBK, SF2 files
* Export of SF2 files

etc. etc. etc. :)


What do you need to run the program:
------------------------------------

* Windows 95/NT/Win32s 1.3
* A Sounblaster AWE32 compatible soundcard (AWE32, SB32 etc.)
* The new SF2 drivers (these include AweMan32.dll)
  You can get these at 

		http://www.creaf.com 

  They will also add some nifty things like full-duplex-
  capabilities to your Awe32.



Installing the program:
-----------------------

Unzip AweVBank96B1000.zip into a temporary directoy and start 'setup.exe'.



Uninstalling the program:
-------------------------

AweVBank 96 fully supports the Win95 uninstall-feature. If you want to get
rid of it, go to your System-Control and select Software. Double-click on the
'AweVBank 96' entry.
